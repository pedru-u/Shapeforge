Hey, welcome to Shapeforge!

Shapeforge is the final version of my A-Level Computer Science NEA Project.
It's a roguelike dungeon crawler with point and click movement meant to copy the MOBA style of movement.

To download and test the game feel free to download the ZIP file inside of the downloads folder in the repository!

The commands can be found below:

Movement: Right-Click

Basic Attack: Q

Abilities: 1,2,3 for each ability

To exit the shop press ESC

That's all! Enjoy playing and feel free to leave a comment!
